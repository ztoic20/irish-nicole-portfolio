# Irish Nicole Palomo — Web Design Portfolio

A responsive seven-page student portfolio built with HTML, CSS, and a small amount of JavaScript. It uses the green visual theme requested for the project and includes the supplied photographs and eight lesson presentations (converted to PDF for convenient viewing).

## Pages
1. **Home** — portfolio welcome, purpose, page directory, and accessibility statement.
2. **Instructor** — Web Design instructor profile.
3. **About Me** — student profile and family photo gallery.
4. **Lessons** — all eight course units, with embedded PDF previews and open/download links.
5. **Activities** — selected classroom and computer-based activity photographs.
6. **Reflections** — reflection on the learning journey.
7. **Contact** — contact details and a front-end form preview.

## Run the website
- Extract the ZIP file.
- Open `index.html` in a modern browser.
- For the best PDF preview experience, serve the extracted folder with a local web server or upload it to a static hosting service. The lesson PDFs are in `assets/lessons/`.

## Important platform note
This package is a **coded website prototype**, not a published Google Site. Google Sites does not import an HTML website ZIP as a complete editable site. The included `GOOGLE-SITES-REBUILD-GUIDE.md` explains how to recreate the same seven-page design in Google Sites using the lessons from the course.

## Contact form
The form is a front-end preview only. It does not send or store messages. Before publishing, connect a Google Form or an approved form service, as covered in Unit 6. No email address or social media details were supplied, so none have been invented.

## Design system
- Forest green: `#123D2B`
- Deep green: `#1C573D`
- Leaf green: `#347653`
- Sage: `#739B7C`
- Mint: `#DCEBDD`
- Pale background: `#EFF6EF`
- White: `#FFFFFF`
- Typography: system sans-serif stack for fast loading and readable text.
- Components: consistent navigation, page headings, cards, image galleries, buttons, and footer.

## Accessibility and responsive design
- Semantic HTML landmarks and heading hierarchy.
- Skip-to-content link.
- Descriptive alt text for informative images.
- Visible keyboard focus.
- High-contrast text and buttons.
- Responsive layouts for desktop, tablet, and mobile.
- Reduced-motion preference support.
- Lesson PDF previews include direct open/download alternatives.

## Source materials
The eight lesson PDFs were converted from the PowerPoint presentations supplied in this conversation. Their unit sequence and lesson topics are retained.
