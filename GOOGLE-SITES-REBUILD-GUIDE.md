# Google Sites Rebuild Guide
## Irish Nicole Palomo — Web Design Portfolio

This guide maps the coded portfolio into Google Sites. It follows the course topics in the supplied units, especially website planning, themes, pages, content blocks, embeds, branding, accessibility, mobile preview, and publishing.

> The HTML ZIP is a visual and content prototype. Google Sites does not import it as a complete editable site. Recreate the pages using the Google Sites editor.

## 1. Plan the site (Unit 2)
**Purpose:** Present Irish Nicole Palomo's Web Design learning journey, course materials, class activities, instructor information, and reflections.

**Target audience:** The course instructor, classmates, and visitors reviewing the student's academic portfolio.

**Site map:**
- Home
- Instructor
- About Me
- Lessons
- Activities
- Reflections
- Contact

**Content plan:** Use the supplied profile and instructor photos, two family photos, five activity photos, the eight lesson presentations, and the written sections in the prototype.

**Basic wireframe (shared page structure):**

```text
┌──────────────────────────────────────────────────────────┐
│ Logo / Portfolio Name             Main Navigation        │
├──────────────────────────────────────────────────────────┤
│ Page Banner: eyebrow + page title + short introduction   │
├──────────────────────────────────────────────────────────┤
│ Main Content: image + text / cards / gallery / documents │
│                                                          │
│ Secondary Content: related links or supporting details   │
├──────────────────────────────────────────────────────────┤
│ Footer: student details + page links + copyright         │
└──────────────────────────────────────────────────────────┘
```

**Home page wireframe:** Header → two-column welcome hero (introduction + profile photo) → three learning-feature cards → portfolio page links → accessibility statement → footer.

**Lessons page wireframe:** Header → page title → short viewing instructions → two-column unit cards on desktop (one column on mobile) → PDF preview and direct open/download links → footer.

## 2. Apply the brand style guide (Units 2 and 6)
Use a consistent green palette throughout the site:
- Primary / forest green: `#123D2B`
- Deep green: `#1C573D`
- Leaf green: `#347653`
- Sage: `#739B7C`
- Mint: `#DCEBDD`
- Pale green background: `#EFF6EF`
- White: `#FFFFFF`

Use one readable sans-serif font family consistently. Keep headings, body text, buttons, image captions, and spacing consistent across all pages. Use the “IN” monogram as a simple text-based logo if desired. Do not stretch or recolor the supplied photographs.

## 3. Create the Google Site (Unit 5)
1. Open Google Sites and create a blank site.
2. Set the site name to **Irish Nicole Palomo | Web Design Portfolio**.
3. Open **Themes** and choose a simple theme. Customize it with the green colors and readable font pairing above.
4. Open **Pages** and create the seven pages in the site map order.
5. Use top navigation. Keep the same page order and labels throughout the site.
6. Add content with text boxes, image blocks, buttons, galleries, dividers, and embedded files. Leave whitespace between sections.

### Instructor

### About Me

### Lessons

### Activities
- Add the five activity photographs in a gallery or two-column layout.

### Reflections
- Add the reflection text, four learning-category cards, and the personal reminder quotation.

### Contact
- Add the contact introduction and student/course details.
- To receive messages, create a Google Form and embed it using **Insert → Forms** or the available embed option. Test the form permissions and mobile display.
- Do not publish the preview form as a working contact form until it is connected to a real submission destination.

## 5. Accessibility and mobile checks (Unit 7)
- Add descriptive alt text to every informative image.
- Use high contrast between text and background.
- Use clear, logical headings and descriptive link labels.
- Keep font sizes readable and avoid putting important text inside images.
- Preview the site in desktop, tablet, and phone views.
- Check for clipped content, horizontal scrolling, small tap targets, and unreadable embedded PDFs or forms.
- Test every internal and external link.
- Ensure embedded Drive files and Forms have the correct sharing permissions.

## 6. Publish and review (Units 5 and 7)
1. Use Preview to check each device layout.
2. Test navigation, buttons, image galleries, PDFs, and the contact form.
3. Confirm the site sharing settings are appropriate.
4. Click **Publish**, choose the site web address, and confirm who can view it.
5. Open the published URL in a separate browser and test it again.
6. Republish after making future changes.

## 7. Prepare the five-minute presentation (Unit 8)
Suggested order:
1. Introduce the purpose and target audience of the portfolio.
2. Explain the green brand colors, typography, and page structure.
3. Demonstrate the Home, Instructor, About Me, Lessons, Activities, Reflections, and Contact pages.
4. Show how lesson PDFs and the contact Google Form are embedded.
5. Demonstrate mobile preview, accessibility features, and working navigation.
6. Invite feedback and mention improvements that could be made.
